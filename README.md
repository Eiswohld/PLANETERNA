# Solaris – Solsystemet 🪐

Detta är ett litet skolprojekt som visar vårt solsystem. Användaren kan klicka på planeterna för att få mer information via en overlay.

## Funktioner ✨

- Visa alla planeter i solsystemet
- Klickbara planeter med detaljerad information:
  - Omkrets
  - Avstånd från solen
  - Månar
  - Kort beskrivning
- Felmeddelanden visas i overlay vid problem med API

## Teknologier 🚀

- HTML, CSS, JavaScript (Vanilla)
- Hämtar planetsdata från ett REST API
- GitHub används för versionshantering
